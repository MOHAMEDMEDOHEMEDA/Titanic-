# Titanic

A SwiftUI-based iOS application inspired by the Titanic project from the "Deep Dive iOS 26 & SwiftUI 6" course. This project was built to practice modern iOS development concepts, UI design, navigation, state management, and SwiftUI best practices.

## Overview

Titanic is a learning project that demonstrates how to build a modern iOS application using SwiftUI and Apple's latest development tools. The project focuses on creating a clean user interface, reusable components, and responsive user interactions.

## Features

* Modern SwiftUI user interface
* Navigation and screen transitions
* Reusable SwiftUI components
* State management using SwiftUI property wrappers
* Responsive layouts for different screen sizes
* Clean and maintainable code structure

## Tech Stack

* Swift
* SwiftUI
* Xcode
* iOS

## What I Learned

Through this project, I gained hands-on experience with:

* Building user interfaces with SwiftUI
* Managing application state
* Creating reusable views and components
* Navigation patterns in SwiftUI
* MVVM principles
* Modern iOS development best practices

## Getting Started

### Prerequisites

* Xcode 26 or later
* iOS Simulator or physical iOS device
* macOS

### Installation

1. Clone the repository

```bash
git clone https://github.com/MOHAMEDMEDOHEMEDA/Titanic.git
```

2. Open the project in Xcode

```bash
open Titanic.xcodeproj
```

3. Build and run the project using the iOS Simulator or a physical device.
